# P1 acceptance report

Status: accepted. The exact candidate passed independent verification from a fresh checkout.

P1 adds a real Codex worker, an isolated Git worktree, independent command
verification, bounded process lifetime, and evidence tied to the exact candidate
and verification inputs. Product source stays under `src/`. Independent checks
stay under `tests/spec/p1/`.

## Independent authorship

BP-1 authored the public contract, schema and CLI stubs, fixtures, and acceptance
scenarios. BP-2 supplied the gate runner and harness sanity checks. Separate
learning and review agents tested Codex, the Windows sandbox, process lifetime,
and host configuration before product implementation. PRODUCT-1 implements in
`.worktrees/product-p1` and cannot edit the frozen bundle.

## Supported scope

The proven environment is Windows, Node 22.22.3, and Codex CLI 0.157.1 with its
existing native sandbox setup. Runs use a configured native executable, explicit
permissions, no inherited MCP table, and external pinned verification inputs.
Project Codex configuration is rejected. The operator supplies credential paths
to deny. The scope is approved local projects, not hostile multi-tenant execution.
P1 does not resume interrupted runs, resolve human decisions, repair failures,
or deliver changes. Those remain later phases.

Research observations and their limits are in
[P1 runtime findings](../research/p1-runtime.md). The original specifications and
P0 acceptance remain unchanged.
