## Dependency audit observation

The fresh install reported one moderate advisory for pinned AJV 8.17.1:
[GHSA-2g4f-4pwh-qvx6](https://github.com/advisories/GHSA-2g4f-4pwh-qvx6).
The [upstream fix](https://github.com/ajv-validator/ajv/releases/tag/v8.18.0)
concerns dynamic `$data` pattern handling. None of the five factory validators
enable `$data`, and product schemas do not use it. A direct check of the
installed package confirmed that the disabled option rejects a benign dynamic
pattern schema. The reported attack path is not enabled by this configuration.
This scoped finding does not remove the package advisory. Audit output and
triage are retained under `.p5-proof/dependency-audit.json` and
`.p5-proof/dependency-triage.md`. Dependency pins stayed unchanged during the
gate. A later update needs its own validation.
