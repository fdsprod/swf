## Dependency evidence

deterministic commits, attributes, hooks, and create-only push behavior. The
[check-runs probe](../research/p5-ci.md) covers paginated API response shapes.
Ambiguous repeated checks remain pending because these observations do not
establish an ordering authority.

The [credential probe](../research/p5-credentials.md) uses dummy credentials and
loopback HTTP. It proves native helper quoting and configuration isolation.
It also shows that the gh helper does not itself enforce an exact GitHub host
policy. Delivery needs its canonical HTTPS target, scoped helper configuration,
and disabled redirects. This evidence does not prove real HTTPS push rights.

The [shared-object probe](../research/p5-shared-objects.md), committed before
dependent implementation, proves the combination of a factory-owned Git
directory, private index and worktree, and the canonical source object store.
It preserves the source checkout and excludes its configured hooks, filter,
helper, info attributes, and URL rewrite. All 49 local Git commands passed.
It does not relax the unsupported-representation policy or replace live proof.
